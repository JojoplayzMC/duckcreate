How to Install the Modpack

Prism Launcher Recommended

  1. Visit the Prism Launcher download page and download the installer.
  2. Run the file and install the program.
  3. Sign into your Minecraft account in the launcher.
  4. Download the DuckCreate .mrpack file.
  5. Open Prism Launcher and click Add Instance > Import > Browse.
  6. In the file selector, select duckcreate.mrpack from your Downloads folder and click OK.
  7. Check "I trust this modpack and wish to proceed regardless" and press OK (This appears because we include custom verification mods not hosted on CurseForge/Modrinth).
  8. Press OK if another window appears and wait for the modpack to finish downloading.
  9. Double-click the DuckCreate instance to launch!
Troubleshooting: If your game fails to launch and opens a log window: Click Settings on the left panel > Java tab > click Detect and select Java 21 or higher. Check "Skip Java compatibility checks" and press close.

Modrinth App

  1. Download and install the Modrinth App.
  2. Download the DuckCreate .mrpack file.
  3. Open the Modrinth App and click the + (Plus) icon in the bottom-left corner to add an instance.
  4. Select From File or Import from file.
  5. Select the downloaded duckcreate.mrpack file and click Create.
  6. Wait for the assets and mods to finish downloading.
  7. Click on the profile card and hit Play.

CurseForge Launcher

  1. Download and install the CurseForge App.
  2. Download the DuckCreate .zip file.
  3. Open CurseForge and select Minecraft from the home dashboard.
  4. Click Create Custom Profile at the top.
  5. Click the Import link at the top of the creation popup.
  6. Select the downloaded duckcreate.zip file and click Open.
  7. CurseForge will create the instance and automatically install the required mods.
  8. Once finished, click Play.

Default Minecraft Launcher (Manual Install)

  1. Download and install Fabric Installer for Minecraft (make sure to select the correct Minecraft version used by DuckCreate).
  2. Run the Fabric installer and click Install to add the Fabric profile to your official launcher.
  3. Download the DuckCreate .zip file and extract its contents.
  4. Open the Run dialog by pressing Win + R, type %appdata%\.minecraft, and press Enter.
  5. Open the mods folder inside .minecraft (create the folder if it doesn't exist).
  6. Copy all mod .jar files from the extracted duckcreate.zip into your .minecraft/mods folder.
  7. Open the official Minecraft Launcher, select the Fabric Loader profile from the bottom left dropdown, and press Play.
Note: Make sure Java 21 or higher is installed on your computer if you encounter launch errors with modern Minecraft versions.
